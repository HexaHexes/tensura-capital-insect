# Tensura Capital: Insect

The Insect faction capital - the Hive in the warm drylands - for use with the
Tensura Faction Spawn ecosystem.

## What it does

Registers the Insect capital. Once registered, the spawn mod picks it up
automatically: a player who first picks (or reincarnates into) the insect
race is placed at the nearest registered capital to the world spawn, and may
return to it at will.

- **Insect** - a sandstone nest waxed with honeycomb chambers and lit by
  shroomlight, dug into the warm drylands (generates in the deserts,
  badlands and swamps).

Install like any mod, alongside Tensura Faction Spawn.

## Dependencies

| | Mod | Why |
|---|---|---|
| Required | Minecraft | - |
| Required | NeoForge | - |
| Required | Tensura Faction Spawn | Owns the central capital tags and arrival behaviour |
| Required | Tensura: Reincarnated | Owns the spawn behaviour the capital serves |
| Required | Mysticism | Owns the insect race the capital serves |
